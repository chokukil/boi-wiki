누가 이 Action을 사용할까요?

팀 Action도 Langflow 연결 키는 endpoint 소유자의 서버 저장값을 사용하고, Wiki 권한과 개인 초안 소유자는 실제 호출자 기준입니다.

Action은 API·MCP·Webhook·Manual·Event Broker·BoI Writer·Langflow를 같은 계약으로 다룹니다. 이 화면에서는 선택한 exact Flow만 Langflow connector binding으로 붙이며, Action의 업무 입출력 계약과 승인 정책은 connector와 분리해 저장합니다.

배포 상태와 검증 상태는 분리됩니다. Agent Hub 배포 후 같은 endpoint/project에서 exact Flow를 찾고 검증해야 합니다.
